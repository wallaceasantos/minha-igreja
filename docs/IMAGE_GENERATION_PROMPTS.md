## 📐 Especificações Técnicas

### Para Midjourney:
```
--ar 16:9 --v 6 --style raw --q 2
```

### Para DALL-E 3:
```
Use detailed, professional style. Modern UI/UX design.
Clean and minimalist. High contrast for readability.
```

### Para Stable Diffusion:
```
Steps: 30-50
CFG Scale: 7-9
Sampler: DPM++ 2M Karras
Model: Realistic Vision ou similar
Negative prompt: blurry, low quality, distorted, ugly, deformed
```

---

## 💡 Dicas para Melhores Resultados

1. **Use "UI design" ou "Figma"** no prompt para estilo mais profissional
2. **Especifique "Brazilian Portuguese"** para textos em português
3. **Adicione "modern SaaS"** para estilo de plataforma moderna
4. **Use "clean and minimalist"** para design limpo
5. **Especifique a proporção** `--ar 16:9` para formato widescreen
6. **Para Midjourney v6**, use `--style raw` para resultados mais realistas
