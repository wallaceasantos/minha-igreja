6: 1. DESCRIÇÃO RESUMIDA DO PROJETO
7: Contexto:
O projeto IGREJA CONNECT surge da necessidade de digitalizar e modernizar a gestão de igrejas cristãs no Brasil. Muitas igrejas de pequeno e médio porte não possuem recursos para desenvolver sistemas próprios de gestão, resultando em processos manuais, desorganizados e ineficientes.
8: Oportunidades Identificadas:
9: Mercado de igrejas cristãs no Brasil representa mais de 100 milhões de fiéis
10: Falta de soluções acessíveis e específicas para o nicho religioso
11: Crescente digitalização de serviços religiosos pós-pandemia
12: Necessidade de gestão profissional de membros, eventos, finanças e comunicação
13: Solução:
Desenvolvimento de uma plataforma SaaS (Software as a Service) multi-tenant que permite que igrejas de diferentes portes tenham seu próprio sistema de gestão completo, incluindo:
14: Dashboard administrativo para pastores e líderes
15: Site público personalizado para cada igreja
16: Gestão de membros, eventos, cultos e ministérios
17: Pedidos de oração online
18: Integração com Google Maps
19: Sistema de planos (Free e Essencial)
20: Justificativa:
O projeto visa democratizar o acesso à tecnologia para igrejas, oferecendo uma solução completa e acessível que permite aos líderes focarem em seu ministério principal enquanto o sistema cuida da gestão administrativa e digital.

88: 5. PREMISSAS E RESTRIÇÕES
89: Premissas
90: A equipe terá acesso a ambiente de desenvolvimento, homologação e produção
91: Os stakeholders estarão disponíveis para validações e feedbacks durante as sprints
92: A infraestrutura de cloud (AWS/Azure) estará disponível e estável
93: As APIs de terceiros (Google Maps, SendGrid, Mercado Pago) permanecerão operacionais
94: O cliente (igrejas) possuirá acesso mínimo à internet para utilizar a plataforma
95: A plataforma será acessada via browser, não sendo necessário desenvolvimento de app mobile
96: Restrições
97: Orçamento: Limitado para contratação de ferramentas premium
98: Tempo: Prazo máximo de 6 meses para MVP em produção
99: Tecnologia:
100: Frontend: React + TypeScript + Vite + TailwindCSS
101: Backend: Node.js + Express + MySQL
102: Hospedagem: Hostinger ou similar
103: Equipe: Time enxuto de 8 pessoas
104: Conformidade: Necessário seguir LGPD para tratamento de dados dos fiéis
105: Segurança: Dados sensíveis (pedidos de oração) devem ser criptografados
106: Planos: Apenas 2 planos disponíveis (Free e Essencial)
107: Recursos Desejáveis
108: Ambiente de CI/CD automatizado
109: Monitoramento contínuo (Sentry, New Relic)
